# FLOPS and FLOPs
**FLOPs** = Floating point operations = it is a common metric used to measure the computational complexity or mathematical calculation to generate each input of the machine learning model. = a total measurement of the mathematical computation

**FLOPS** = Floating point operation per second = It is a measurement metric used to indicate the hardware performance of processor like GPU used to train and run the AI model. = **Hardware benchmarking** = how fast the processor can run.
