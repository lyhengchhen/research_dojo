# MLE
It is a statistical method used to find the best-git parameters for a probability distribution by maximizing a likelihood function, making the observed data as probable as possible 
To simply put, it is used to find the best parameter. 

As a side note that worth remembering, the MLE has no single formula. but there is a universal step-by-step recipe used to find the formula for any specific distribution. 

For example: Bell curve (normal distribution mean)
If the sample data from a normal distribution, so what is the true population mean ($\mu$)
so the formula for MLE in this case is:$$ \hat{\mu} = \frac{1}{n}\sum^{n}_{i=i}x_{i}$$
